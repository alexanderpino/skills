# Generated frames

Everything in this directory is **output**, regenerated by the drivers beside it, and
nothing here is committed — a frame is evidence for the run that produced it, and a
stale PNG in a repository is a claim nobody re-checked.

    python3 ../beach_render.py --scene          # the current scene: frames J, K, F
    python3 ../beach_render.py --scene --fast   # the same code path at 180 x 240
    python3 ../beach_evidence.py                # the coastal diagnostic set
    python3 ../beach_diffract_evidence.py       # Sommerfeld's half-plane and the fan
    python3 ../foam_evidence.py                 # the foam realisation and its texture
    python3 ../wind_spectrum_figures.py         # the derived spectrum and its limits
    python3 ../pool_figures.py                  # the pool set

Set `BEACH_OUT` to write somewhere else.

**The committed images live in `../../references/figures/`** and are drawn by one
script, `make_figures.py`, which imports this directory read-only and writes no
physics of its own — so a figure in a chapter cannot drift from the code that ships.
The frames here are for looking at while working; the figures there are the ones a
chapter is allowed to cite.
