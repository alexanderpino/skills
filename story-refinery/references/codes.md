# Validator codes

Generated by `python scripts/validate.py --codes --markdown`; selftest fails when this file is stale. A code is the stable identifier of a finding. Severity is what the call sites use: `error | warn` has call sites at both, `config` is decided by a rule in `refinery.yaml`.
