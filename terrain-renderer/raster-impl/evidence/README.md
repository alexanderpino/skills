# Generated frames

Output, regenerated by `../evidence.py`, and nothing here is committed — a frame is
evidence for the run that produced it, and a stale PNG in a repository is a claim
nobody re-checked.

    python3 ../evidence.py            # all eight figures
    python3 ../evidence.py r2-        # just the wave set

Set `RASTER_OUT` to write somewhere else. The committed images of this skill live in
`../../references/figures/`.
